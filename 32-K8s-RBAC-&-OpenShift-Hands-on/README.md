# Kubernetes RBAC & OpenShift Hands-on

This project covers Kubernetes RBAC fundamentals and hands-on practice using OpenShift sandbox. It includes real-world debugging of application exposure and networking.

## Topics Covered

- Kubernetes RBAC (Role, RoleBinding, ClusterRole)
- Service Accounts
- Authentication & Authorization
- OpenShift CLI (oc)
- Deployment, Service, Route
- Kubernetes Networking Flow
- Debugging real issues

## Projects Done

- NGINX Deployment on OpenShift
- Service & Route Exposure
- Debugging Service-Selector Issue
