# Kubernetes Cluster Setup using KOPS (AWS)

This project demonstrates how to create, manage, and delete a Kubernetes cluster on AWS using KOPS with both local and production-level understanding.

## Topics Covered

- KOPS basics and working
- Kubernetes cluster lifecycle
- S3 state store concept
- Gossip vs DNS-based clusters
- Route53 integration (production setup)
- Environment variables usage
- Cluster creation, validation, and deletion
