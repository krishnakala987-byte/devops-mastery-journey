## Networking Fundamentals (IP, Subnet, CIDR, Ports, Bits & Bytes)

This repository contains my learning notes on core networking concepts required for DevOps. It covers IP addressing, subnetting, CIDR, ports, and the basics of bits and bytes in a simple and practical way.

## Topics Covered

- IP Address (IPv4, Private vs Public)
- Subnets (Network segmentation)
- CIDR (IP range calculation)
- Ports (Application access points)
- Bits & Bytes (Binary fundamentals)
- Binary representation of CIDR
