
# Linux Disk Management & AWS EBS Hands-on

This project covers practical Linux disk management concepts along with AWS EBS volume attachment, formatting, mounting, and persistence.

## Topics Covered
- Linux filesystem and mounting
- EBS volume attachment in AWS
- Disk formatting and mounting
- Permissions and ownership
- fstab for persistent storage
- Debugging real-world issues

## Projects Done
- Attach and Mount EBS Volume
- Persistent Storage Setup with fstab
