# Kubernetes First Application Deployment (Minikube)

This project demonstrates how to deploy a basic application in Kubernetes using Minikube and kubectl, along with debugging real-world issues.

## Topics Covered
- Containers vs Pods
- Kubernetes Basics
- Minikube Setup
- kubectl Usage
- Pod Creation using YAML
- Debugging Kubernetes Issues
- Exposing Applications using Services

## Projects Done
- Nginx Pod Deployment
- Nginx Service Exposure
