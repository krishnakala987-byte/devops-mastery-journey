# DevOps Project Management Tools & Workflow

A beginner-friendly guide to understanding how work is managed, tracked, and delivered in real-world DevOps environments using Agile methodology and industry tools.

## Topics Covered

- Agile Methodology (Sprint, Backlog, Standups)
- Kanban Board Workflow
- Jira (Task Tracking)
- Confluence & SharePoint (Documentation)
- ServiceNow (Incident & Change Management)
- Git & GitHub Projects (Code + Task Management)
- Read the Docs (Open-source Documentation)
