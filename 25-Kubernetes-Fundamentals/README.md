## Topics Covered

- Docker vs Kubernetes
- Kubernetes Architecture (Control Plane & Data Plane)
- Core Components (API Server, Scheduler, etcd, Kubelet, Kube-proxy)
- Container vs Pod vs Node
- Auto-healing, Auto-scaling, Load Balancing
