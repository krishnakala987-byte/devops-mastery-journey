# Kubernetes Deployments, ReplicaSets & Scaling

This project covers core Kubernetes concepts like Pods, ReplicaSets, and Deployments with hands-on practice using Minikube.

## Topics Covered
- Pod vs Deployment
- ReplicaSet and Auto-Healing
- Scaling Pods
- Kubernetes Networking (Pod IP)
- kubectl Commands

## Projects Done
- Nginx Pod Deployment
- Deployment with Replica Scaling
- Auto-Healing Demonstration
