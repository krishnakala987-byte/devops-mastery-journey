# Kubernetes Monitoring with Prometheus & Grafana

This project demonstrates how to monitor a Kubernetes-based Python application using Prometheus and Grafana. It covers exposing services, verifying metrics, and visualizing real-time data.

## Topics Covered
- Kubernetes Services (ClusterIP, NodePort, LoadBalancer)
- Prometheus metrics collection
- Grafana dashboards and visualization
- Port forwarding and service exposure
- Debugging service-to-pod connectivity

## Projects
- Python App Deployment on Kubernetes
- Prometheus Monitoring Setup
- Grafana Dashboard Visualization
