## Kubernetes ConfigMaps, Secrets & Custom Resources (CRD/CR/Controller)

Short notes and hands-on practice for understanding how Kubernetes manages configuration, secrets, and extends its capabilities using Custom Resources.

### Topics Covered
- ConfigMaps (env & volume)
- Secrets (base64, usage, decoding)
- Deployment integration
- Debugging inside containers
- Custom Resource Definition (CRD)
- Custom Resource (CR)
- Custom Controller concept

### Projects Done
- ConfigMap with Environment Variables
- ConfigMap with Volume Mount
- Secret Creation and Decoding
- Python App Deployment with Config Injection
