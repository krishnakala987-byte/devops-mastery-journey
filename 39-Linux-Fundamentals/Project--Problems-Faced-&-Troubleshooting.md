## 1. Step-by-Step Project Implementation

### Project 1: Setup Linux using WSL

1. Enable WSL in Windows
2. Install Ubuntu from Microsoft Store
3. Open terminal
4. Set username and password
5. Update system:
```
sudo apt update
sudo apt upgrade
```
6. Start using Linux commands

---

### Project 2: Setup Linux using Docker

1. Install Docker
2. Pull Ubuntu image:
```
docker pull ubuntu
```
3. Run container:
```
docker run -it ubuntu
```
4. You are now inside a Linux environment
5. Start practicing commands

## 6. Mistakes & Things to Remember 

- Linux is not a single OS, it's a kernel
- Distributions are built on top of Linux
- Always use `sudo` carefully (admin access)
- Practice CLI daily (very important for DevOps)
- Do not depend only on theory, practice commands
- Understand concepts instead of memorizing

---

## 7. Quick Revision Summary

- OS = bridge between user and hardware
- Linux = open-source, secure, used in servers
- Kernel = core of Linux
- Shell = where we type commands
- Distros = Ubuntu, Red Hat, Alpine
- Use WSL or Docker for local practice
- apt = package manager in Ubuntu

Keep practicing commands regularly to gain confidence.
