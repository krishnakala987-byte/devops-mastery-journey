# Kubernetes Services & Load Balancing (Hands-on)

This project demonstrates how Kubernetes Services work, including service discovery, load balancing, and exposing applications using NodePort and LoadBalancer.

## Topics Covered
- Kubernetes Services (ClusterIP, NodePort, LoadBalancer)
- Labels and Selectors
- Service Discovery
- kube-proxy and Load Balancing
- Minikube Networking
- KubeShark Traffic Visualization

## Projects Done
- Django App Deployment on Kubernetes
- Service Exposure using NodePort and LoadBalancer
- Load Balancing Verification using Logs and KubeShark
