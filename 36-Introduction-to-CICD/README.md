
# CI/CD (Continuous Integration and Continuous Delivery)

A practical guide to understanding CI/CD pipelines, automation in DevOps, and modern vs legacy approaches used in real-world systems.

## Topics Covered
- CI vs CD fundamentals
- CI/CD pipeline stages
- Testing types (Unit, Integration, E2E)
- Code quality and security checks
- Build and artifact concepts
- Deployment process
- Jenkins vs modern CI/CD tools
- Event-driven pipelines
